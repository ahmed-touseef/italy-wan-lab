      How this page works

      The network runs on a cloud server: 54 containers built from one Python file. Every 15 seconds a script runs show commands, pings and traceroutes inside the lab and saves the results. This page only reads them, so nothing here can change the network.

      Remote PCs join over WireGuard and appear on the map, tunnelled into Milan. Their home addresses and keys never reach this page.

      To see failover, the Milan to Naples cable can be cut. Within seconds OSPF sends Milan's traffic for Rome the long way round through Turin, and this page shows the new path on its next refresh.
